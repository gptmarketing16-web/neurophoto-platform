# NeuroPhoto v7.2

- исправлено удаление фото-, промпт- и проектных блоков при S3-хранилище;
- удаление записей больше не зависит от медленного обхода S3-префикса;
- S3-очистка выполняется безопасно и не превращает действие пользователя в HTTP 500;
- добавлены короткие сетевые таймауты S3;
- RQ worker переведён на SimpleWorker для меньшего потребления памяти на Render Free;
- фоновая очистка запускается раз в 3 минуты вместо каждой минуты.
