# NeuroPhoto Platform v7.7

1. Карточки блоков-промптов стали компактнее: большое поле текста заменено статусом «Промпт подключён», а референс занимает основную область карточки.
2. Клик по свободной части блока, включая референс, открывает правую рабочую панель.
3. В панели редактируются название, промпт, блокировки, референс, модель, формат, количество результатов и качество.
4. Кнопка «Сохранить» сохраняет выбранный блок и закрывает панель.
5. Кнопка «Генерировать» в панели сначала явно сохраняет выбранный блок, затем запускает генерацию.
6. Кнопка «Генерировать» на карточке работает только с уже сохранёнными данными и предупреждает о несохранённых изменениях.
7. Убраны скрытые автосохранения при переключении проекта, обновлении статусов, загрузке файлов и дублировании.
8. Несохранённые изменения сохраняются только по кнопке «Сохранить изменения», кнопке панели «Сохранить» или перед генерацией из панели.
9. При переходе в другой проект показывается предупреждение о потере несохранённых изменений.
10. Для изображений включены отложенная загрузка и асинхронное декодирование, а ввод текста в панели не перерисовывает весь canvas.
