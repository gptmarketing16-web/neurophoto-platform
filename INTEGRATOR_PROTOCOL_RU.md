# Подключение внешнего AI-интегратора

NeuroPhoto Platform поддерживает два режима для каждого провайдера:

1. **Прямое API** — стандартный OpenAI или Gemini API.
2. **Интегратор** — произвольная платформа, которая принимает единый multipart-запрос NeuroPhoto Bridge.

## Запрос к интегратору

Метод: `POST` на URL, указанный в админ-панели.

Тип: `multipart/form-data`.

Текстовые поля:

- `prompt` — системный промпт конкретного блока;
- `model` — выбранная модель;
- `output_count` — число результатов;
- `aspect_ratio` — формат, например `4:5` или `auto` уже преобразованный в фактическое значение;
- `quality` — `high`, `medium` или `low`.

Файлы:

- повторяющееся поле `images`;
- сначала передаются все связанные фотографии заказчиков;
- последним передаётся референс конкретного промпт-блока.

Авторизация настраивается в интерфейсе:

- имя заголовка, например `Authorization` или `X-API-Key`;
- префикс, например `Bearer` или пустое значение;
- токен.

## Допустимый ответ

### Base64

```json
{
  "images": [
    {"base64": "iVBORw0KGgo..."},
    {"b64_json": "iVBORw0KGgo..."}
  ],
  "usage": {
    "input_tokens": 1000,
    "output_tokens": 2000,
    "total_tokens": 3000
  }
}
```

### Ссылки

```json
{
  "images": [
    {"url": "https://example.ru/result-1.png"},
    {"url": "https://example.ru/result-2.png"}
  ]
}
```

Вместо `images` допускается массив `data`.

## Если API интегратора отличается

Нужен небольшой адаптер в `backend/app/services/image_provider.py`. Для его создания достаточно документации интегратора и одного тестового запроса/ответа без реальных клиентских фотографий.
