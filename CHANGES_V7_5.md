# NeuroPhoto Platform v7.5

1. Проекты разделены на два пространства: `AI-агенты` и `Users`.
2. При создании проекта владелец выбирает тип. Проект AI-агента становится конвейером; менеджерам он доступен только для просмотра.
3. Серверная защита блокирует любые изменения, загрузки и ручные генерации в агентском проекте для всех, кроме владельца.
4. В списке агентских проектов показываются число заказов в очереди и число заказов в работе.
5. Заложен защищённый API приёма подготовленных заявок: `POST /api/automation/orders`.
6. Заявки распределяются по свободным агентским проектам с совпадающей тематикой; при занятых линиях остаются в очереди.
7. Референсы показываются полностью через `object-fit: contain`, без обрезания сверху и снизу.
8. Добавлены отдельные инструменты «Курсор» и «Рука» (`V`, `H`, временная рука — пробел).
9. `Shift + drag` на пустом поле выделяет несколько объектов рамкой.
10. Стрелки двигают выделенные объекты, а без выделения — рабочее пространство.

## Формат будущего FASE2ID → NeuroPhoto

```http
POST /api/automation/orders
Authorization: Bearer <AUTOMATION_API_TOKEN>
Content-Type: application/json
```

```json
{
  "external_order_id": "AVITO-4821",
  "customer_name": "Анна Иванова",
  "source": "avito",
  "theme": "СВО",
  "generation_numbers": [2, 7, 11],
  "priority": 100,
  "payload": {
    "people": [],
    "selected_photos": [],
    "details": ""
  }
}
```

До подключения FASE2ID отдельный `AUTOMATION_API_TOKEN` можно не задавать: временно используется `APP_SECRET_KEY`. Для реальной интеграции рекомендуется создать отдельный токен.
