# NeuroPhoto Platform v7.5 — Render + Supabase + Upstash

Онлайн-версия NeuroPhoto Canvas с отдельными пространствами для менеджеров и AI-конвейеров.

## Новое в v7.5

- разделы `🤖 AI-агенты` и `👥 Users` с отдельными списками и счётчиками;
- выбор типа при создании проекта;
- агентские проекты полностью защищены от вмешательства менеджеров на интерфейсе и сервере;
- фундамент очереди заявок для будущей связки `BotHunter → FASE2ID → NeuroPhoto`;
- полное отображение референсов без обрезания;
- режимы «Курсор» и «Рука»;
- выделение нескольких объектов рамкой через `Shift + drag`;
- навигация по canvas стрелками, когда объекты не выделены.

Подробности: `CHANGES_V7_5.md`.

Render Free остаётся тестовой средой и может засыпать после периода бездействия.
